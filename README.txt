MetroStack: Quantum Edition

How to run:
1. Open index.html in a browser, or
2. Serve the folder locally with: python3 -m http.server 8000
3. Then visit: http://localhost:8000

Controls:
- Left / Right arrows: move
- Down arrow: soft drop
- Up arrow: rotate
- Space: hard drop

This version is a simple browser-based arcade puzzle inspired by classic stacked-block gameplay.
